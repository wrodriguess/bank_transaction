# Interface

Contrato que define um conjunto de métodos abstratos que uma classe deve implementar,
mas não fornece a implementação desses métodos.

São usadas para especificar métodos que devem ser implementados por uma ou mais classes.

A interface descreve "o que" deve ser feito, deixando o "como" deve ser feito para a classe que a 
implementarão.

## Proposito

Fornecer um contrato que outras classes podem seguir. Isso permite que diferentes classes sejam 
tratadas de maneira uniforme.
